# Network Analysis Lab

This folder is reserved for a documented Wireshark/tcpdump investigation.

For each future lab, include:
- Objective and authorised scope
- Capture source and environment
- Filters or commands used
- Sanitised evidence and observations
- Findings, limitations, and recommendations

Use only public sample captures or traffic from systems you own or are explicitly authorised to inspect. Do not commit private captures or real credentials.
